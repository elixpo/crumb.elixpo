---
name: plan-execute
description: Turn broad implementation requests into small, independently verifiable work packages.
---

1. Identify dependencies, invariants, acceptance criteria, and deferred work.
2. Order packages so each leaves the repository usable and testable.
3. Keep unrelated cleanup outside the active package.
4. Validate proportionally after each package and record unresolved risks.
5. Continue autonomously while safe in-scope work remains; stop only for a real decision or missing authority.
